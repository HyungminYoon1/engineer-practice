# 정보처리기사 실기 학습실

정보처리기사 필답형 실기를 준비하는 학습 앱입니다. 개념을 읽고 답안을 직접 작성하며, 틀린 과정과 다음 복습 시점을 확인합니다.

## 사용 방법

처음이라면 **학습 길잡이**에서 코드·데이터 설계·SQL·운영체제/네트워크·설계/테스트·보안/연계 중 한 주제를 고르세요. 24개 풀이 단계의 설명과 연결 개념을 읽고, 검증된 예제의 실행 과정을 확인한 뒤 다른 조건을 직접 풀 수 있습니다. 설명형 자기 점검 6개도 제공합니다. 길잡이를 읽은 것만으로 풀이 기록이나 숙련도가 올라가지는 않습니다.

1. **진단평가** 20문항으로 학습 출발점을 확인합니다. 시간 제한은 없습니다.
2. **개념 학습**에서 핵심 규칙·예시·혼동 지점·선수 개념을 읽습니다.
3. **문제 풀이**에서 풀이 유형과 조건을 골라 C·Java·Python 출력, SQL 작성·결과, 계산, 상황 판단, 개념 단답을 직접 작성합니다. 제출 후 정답·설명·단계별 상태를 봅니다.
4. **복습 노트**에서 오답 원인과 복습할 개념을 확인합니다. 힌트 없이 시간이 지난 뒤 다시 풀고 다른 조건에서도 확인합니다.
5. **모의시험**은 20문항·150분·100점입니다. 답안·표시한 문항을 자동 저장하고 제출 또는 시간 종료 후 채점합니다. 다른 화면으로 이동해도 제한 시간이 연장되지 않습니다.
6. **학습 기록·설정**에서 하루 학습 시간, 예정일, JSON 백업·복원·삭제를 관리합니다. 문제지와 정답·해설지는 별도로 인쇄할 수 있습니다.
7. **학습 범위**에서 2026 출제기준의 12개 영역별 문제와 개념을 찾아봅니다. 요구사항 추적·UML·정규화·연계·화면·테스트·보안·형상·설치 문서의 상황 문제도 포함합니다.

## 콘텐츠

- 자체 제작 개념 134개, 개념 단답 134문항
- 코드 23유형 × 8변형 = 184문항 (C 72·Java 56·Python 56)
- SQL 13유형 = 95문항 (SQLite, 결과·조회/DDL/UPDATE 작성)
- 계산 15유형 × 5변형 = 75문항 (스케줄링·주소·자원·테스트 집합 등)
- 사례 적용 19유형 × 5변형 = 95문항 (DCL·프로시저·함수는 DBMS 명시)
- 합계 583문항, 응용 풀이 70유형. 수치·분기·입력 조건 변형을 포함하며 583개 독립 풀이 능력을 검증하는 것은 아닙니다.

2026 출제기준을 참고합니다. 기존 88개 개념·304문항만으로 전체 범위나 합격 준비를 충족했다고 볼 수 없었으며, 재검토에서 범위별 응용 문제와 개념을 보강했습니다. 전부 풀었다고 합격이 보장되는 것은 아닙니다. 전체 기출·공식 채점표·회차별 출제 비율을 재현하지 않으며 2027~2029 기준 반영은 별도 검토가 필요합니다. [재검토 결과](docs/audit-20261012.md), [범위와 출처](docs/content-sources.md)를 확인하세요.

## 저장과 실행

계정·서버·Neon·공개 랭킹·AI API를 사용하지 않습니다. 답안은 해당 브라우저의 `engineer-practice-v1`에만 저장합니다. 최대 2048회 풀이·128개 표시 문제·20회 완료 시험·진행 중 시험 1회를 보관합니다.
총 저장량은 공백 정리한 JSON 기준 1,048,576자 이내이며 초과하면 오래된 풀이부터 정리합니다. 진행 중 답안과 설정은 이 정리로 삭제하지 않습니다. 읽기 좋은 JSON 백업의 들여쓰기·줄바꿈은 복원 시 저장 용량과 구분합니다. 입력 파일은 최대 4MiB이며 실제 기록은 기존 저장 한도를 지켜야 합니다. 복원은 기록을 임의로 잘라 넣지 않고 검증 후 교체하며, 복원과 삭제에는 확인 절차가 있습니다. 같은 출처의 다른 Pages 앱과 저장소를 읽을 수 있는 권한을 공유하므로 비밀 정보를 입력하지 마세요.

```sh
npm test
npm run check
npm run verify:native
npm run verify:dialects
npm run dev -- 0
```

Node 22 이상. 실제 정답 검증에는 GCC(C11), JDK 17 이상, Python 3.11 이상이 필요합니다. DBMS별 검증은 Docker에서 네트워크·포트·호스트 마운트 없는 임시 PostgreSQL/MySQL만 사용하고 검증 후 제거합니다. 이것은 개발·CI용이며 실행 앱에는 DB가 없습니다. 사용자 코드를 서버에서 실행하지 않습니다. 런타임 npm 의존성은 없습니다.

GitHub Actions 검증 후 `dist`만 Pages에 배포합니다. 설계는 [architecture.md](architecture.md), 변경 결정은 [결정 기록](docs/decisions.md), 실제 검증 범위는 [검증 기록](docs/verification.md)을 참고하세요.
