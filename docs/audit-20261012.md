# 2026 정보처리기사 실기 학습실 재검토

## 결론

기존 88개 개념·304문항은 12개 주요 영역의 기초가 있었지만 상세 범위 전체를 충족하지 않았습니다. 코드/SQL 정답 실행 검증과 앱 기능 검증을 통과했다는 사실은 시험 대비 충분성이나 합격 가능성의 검증이 아닙니다. 이번에는 미수록 주제의 대표 응용 문제와 개념을 보강하고, 실제 결함을 재현한 뒤 수정했습니다.

[Q-Net 종목 안내](https://www.q-net.or.kr/crf005.do?id=crf00503s02&jmCd=1320&jmInfoDivCcd=B0)는 실기를 필답형 150분, 60/100 이상 합격으로 안내합니다. **필답형이 모든 문제의 장문 서술형을 뜻하지는 않습니다.** 출제기준의 수행 능력은 평가 범위이며 특정 주제의 문항 형태·회차별 비중을 고정하지 않습니다. 앱은 용어·출력·계산·상황 판단·SQL 작성·문법 빈칸으로 연습하며 자체 20문항 배분을 공식 문제 구성으로 주장하지 않습니다.
