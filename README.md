# 정보처리기사 실기 학습실

정보처리기사 필답형 실기를 준비하는 학습 앱입니다. 개념을 읽고 답안을 직접 작성하며, 틀린 과정과 다음 복습 시점을 확인합니다.

## 사용 방법

1. **진단평가** 20문항으로 학습 출발점을 확인합니다. 시간 제한은 없습니다.
2. **개념 학습**에서 핵심 규칙·예시·혼동 지점·선수 개념을 읽습니다.
3. **문제 풀이**에서 C·Java·Python 출력, SQL 결과, 계산, 개념 단답을 직접 작성합니다. 답안 제출 후 정답·설명·단계별 상태를 볼 수 있습니다.
4. **복습 노트**에서 오답 원인과 복습할 개념을 확인합니다. 힌트 없이 시간이 지난 뒤 다시 풀고 다른 조건에서도 확인합니다.
5. **모의시험**은 20문항·150분·100점입니다. 답안·표시한 문항을 자동 저장하고 제출 또는 시간 종료 후 채점합니다. 다른 화면으로 이동해도 제한 시간이 연장되지 않습니다.
6. **학습 기록·설정**에서 하루 학습 시간, 예정일, JSON 백업·복원·삭제를 관리합니다. 문제지와 정답·해설지는 별도로 인쇄할 수 있습니다.

## 콘텐츠

- 자체 제작 개념 88개, 개념 단답 88개
- 코드 16유형 × 8변형 = 128문항 (C 48·Java 40·Python 40)
- SQL 6유형 × 8변형 = 48문항 (SQLite의 명시된 데이터셋)
- 계산 8유형 × 5변형 = 40문항
- 합계 304문항. 변형은 수치·분기·입력 조건을 바꾼 고정 문항이며 304개의 완전히 독립된 풀이 유형은 아닙니다.

2026 출제기준을 참고한 최초 학습 프로필입니다. 전체 기출·공식 채점표·회차별 출제 비율을 재현하지 않으며 2027~2029 기준 반영은 별도 검토가 필요합니다. [범위와 출처](docs/content-sources.md)를 확인하세요.

## 저장과 실행

계정·서버·Neon·공개 랭킹·AI API를 사용하지 않습니다. 답안은 해당 브라우저의 `engineer-practice-v1`에만 저장합니다. 최대 2048회 풀이·128개 표시 문제·20회 완료 시험·진행 중 시험 1회를 보관합니다. JSON 백업은 사용자가 내려받아 보관하며 복원과 삭제에는 확인 절차가 있습니다. 같은 출처의 다른 Pages 앱과 저장소를 읽을 수 있는 권한을 공유하므로 비밀 정보를 입력하지 마세요.

```sh
npm test
npm run check
npm run verify:native
npm run dev -- 0
```

Node 22 이상. 실제 정답 검증에는 GCC(C11), JDK 17 이상, Python 3.11 이상이 필요합니다. 프로그램과 SQLite 질의를 실제 실행하며 사용자 코드를 서버에서 실행하지 않습니다. 런타임 npm 의존성은 없습니다.

GitHub Actions 검증 후 `dist`만 Pages에 배포합니다. 설계는 [architecture.md](architecture.md), 변경 결정은 [결정 기록](docs/decisions.md), 실제 검증 범위는 [검증 기록](docs/verification.md)을 참고하세요.
